# SignalPoint EUDR

Landing page for the EUDR plot-data practice, served at https://eudr.signalpoint.in

Single static file, no build step. Edit `index.html` and push; GitHub Pages redeploys.

Source of truth lives in `eudr-venture/site/index.html`; `standalone.html` is the
generated deployable version (adds doctype, charset, viewport and meta tags).
